# Материалы для подготовки (БИЛ / РФМШ / НИШ)

Источники заданий, по которым изучаем формат и сложность экзаменов.
Задачи из пособий на платформу 1-в-1 не копируем: по ним пишем свои оригинальные.

## Структура

| Папка | Что лежит |
|-------|-----------|
| `_inbox/` | Новые файлы, ещё не разобранные |
| `BIL/` | Білім-Инновация лицейі (приоритет 1) |
| `RFMSH/` | РФМШ (приоритет 1) |
| `NIS/` | НИШ (подключаем позже) |

## Правило имён

`<ШКОЛА>_<тип>_<класс>_<год>_<предмет>.<ext>`, например `BIL_sample-test_6_2024_math.pdf`.

Типы: `spec` (спецификация/правила), `sample-test` (пробный тест), `past-exam` (задания прошлых лет), `book` (пособие), `other`.
