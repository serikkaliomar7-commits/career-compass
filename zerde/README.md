# Зерде — подготовка в БИЛ, РФМШ (и позже НИШ)

Сайт-планировщик для учеников 4–7 классов. Каждый день ученик получает план:
темы (видеоурок → 12 задач с растущей сложностью) и пробный тест.
Интерфейс на казахском, переключается на русский.

## Как запустить

Открыть `zerde/index.html` в браузере — сервер и сборка не нужны.
Прогресс хранится в браузере (localStorage); его можно выгрузить и загрузить в «Баптаулар».

## Как устроено

| Файл | Что делает |
|---|---|
| `js/gen_math.js`, `js/gen_logic.js` | Генераторы задач: 25 тем × 3 уровня (A/B/C). Каждый вариант новый, ответ считает код |
| `js/banks.js` | Задачи, составленные вручную: логика (20) и тексты «Оқу сауаттылығы» (4 текста × 5 вопросов) |
| `js/curriculum.js` | Темы, памятки, поисковые запросы для видео, форматы экзаменов |
| `js/engine.js` | Сборка вопроса (выбор A–D или ввод целого числа), адаптивная практика, пробные тесты и подсчёт баллов |
| `js/planner.js` | План дня, расписание пробных, серия дней, готовность, прогноз баллов, слабые темы |
| `js/app.js`, `css/style.css` | Интерфейс |
| `tests/run.js` | Проверка генераторов и движка: `node zerde/tests/run.js` |

### Форматы экзаменов (см. `materials/EXAM_SPECS.md`)

| | БИЛ (правила 2026–27) | РФМШ (пробный тест 2024) |
|---|---|---|
| Полный пробный | 50 математика+логика + 10 чтение, 110 мин | 30 заданий, 120 мин |
| Ответ | выбор из 4 вариантов | целое число |
| Баллы | +4 / −1 / 0 за пропуск, максимум 240 | A — 3, B — 5, C — 7, максимум 150 |

### Логика обучения

- **Практика по теме:** 12 задач. Два верных подряд → уровень выше, ошибка → ниже.
  Следующая тренировка начинается с достигнутого уровня. ★★★ — от 75% верных и решены задачи уровня C.
- **План дня** фиксируется при первом открытии. Сначала доводим начатые темы, затем новые по программе,
  когда всё освоено — повторяем самые давние.
- **Пробные тесты:** полный — 2 раза в неделю, за 60 дней до экзамена — 3 раза. В остальные дни — короткий тест
  (зависит от выбранной нагрузки).
- **После теста:** разбор каждой ошибки с решением, слабые темы с кнопкой «Тренировать», для БИЛ — совет
  не оставлять пустых ответов (при +4/−1 случайный ответ из 4 вариантов в среднем даёт +0,25).

### Видеоуроки

По умолчанию кнопка «Видеосабақ» открывает поиск на YouTube по теме.
Учитель может вставить ссылку на конкретное видео в «Баптаулар → Видеосабақ сілтемелері».
