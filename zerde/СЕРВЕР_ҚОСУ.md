# Серверді қосу — қадамдап (≈20 минут, тегін)

## 1-қадам. Supabase жобасын ашу (5 минут)
1. **supabase.com** сайтына кіріңіз → **Start your project** → Google немесе GitHub арқылы тіркеліңіз.
2. **New project** басыңыз:
   - Name: `zerde`
   - Database Password: күрделі құпиясөз ойлап табыңыз, оны **ешкімге бермеңіз**, бір жерге жазып қойыңыз.
   - Region: **Central EU (Frankfurt)** (Қазақстанға ең жақыны).
   - Plan: **Free**.
3. **Create new project** → 1–2 минут күтіңіз.

## 2-қадам. Дерекқорды құру (2 минут)
1. Сол жақ мәзірден **SQL Editor** → **New query**.
2. `zerde/supabase/schema.sql` файлының **бүкіл мәтінін** көшіріп, сол жерге қойыңыз.
3. **Run** басыңыз. Төменде «Success» шығуы керек.

## 3-қадам. Кіру баптаулары (3 минут)
**Authentication** бөлімінде:
1. **Sign In / Providers → Email**: қосулы тұрсын. **Confirm email** опциясын бастапқыда өшіріп қоюға болады, сонда оқушылар бірден кіреді.
2. **Policies → Password**: **Minimum length = 8**, **Password requirements = Letters and digits**.
3. **URL Configuration → Site URL**: сайттың мекенжайы (5-қадамнан кейін шығады, мысалы `https://zerde.netlify.app`).

## 4-қадам. Маған 2 нәрсе жіберіңіз
**Project Settings → API** бетінде:
- **Project URL**, мысалы `https://abcdxyz.supabase.co`;
- **anon public** кілті (`eyJ...` деп басталатын ұзын жол).

Бұл екеуі ашық кілттер, оларды жіберу қауіпсіз. Мен оларды сайтқа қосып, сайтты қайта жинаймын.

⚠️ **service_role** кілтін және дерекқор құпиясөзін (Database Password) **ешкімге жібермеңіз, маған да.**

## 5-қадам. Сайтты интернетке шығару (5 минут)
1. **app.netlify.com/drop** сайтын ашып, тіркеліңіз.
2. Мен беретін `zerde-site.zip` архивін ашып, ішіндегі **dist** папкасын сол бетке сүйреп апарыңыз.
3. Сайт бірден ашылады, мысалы `https://zerde-abc123.netlify.app`. Бұл мекенжайды 3-қадамдағы **Site URL** өрісіне жазыңыз.
4. Кейін домен алсаңыз (`zerde.kz`, ps.kz арқылы), Netlify → **Domain management** бетінде қосасыз.

## 6-қадам. Бірінші админ (2 минут)
1. Supabase → **SQL Editor** бетіне мына жолды жазып, **Run** басыңыз (кодты өзгертіңіз):
   ```sql
   insert into public.promo_codes (code, kind, max_uses, note) values ('ӨЗ-КОДЫҢЫЗ-2026', 'admin', 2, 'негізін қалаушылар');
   ```
2. Сайтта тіркеліп, **Аккаунт → Промокод** бөліміне сол кодты енгізіңіз. Сіз енді админсіз.
3. **Әкімші → Баптаулар** бетінде Kaspi нөмірін, алушының атын, бағаларды және реквизиттерді толтырыңыз.
4. **Әкімші → Жүйе** бетінде барлық жол ✓ болуы керек.

## 7-қадам. Тексеру (5 минут)
- Телефоннан оқушы болып тіркеліңіз, бір үй жұмысын шығарыңыз.
- Компьютерден админ болып кіріңіз: **Әкімші → Оқушылар** бетінде сол оқушы көрінуі керек.
- Тариф таңдап, Kaspi-ге аз сома аударып, **Төледім** басыңыз. Админ болып растаңыз, сонда оқушыға қолжетімділік ашылуы керек.
