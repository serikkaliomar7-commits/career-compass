# Как запустить «Зерде» для продажи

Сейчас сайт работает в **демо-режиме**: аккаунты, оплаты и промокоды хранятся только в браузере.
Так удобно показывать и проверять, но **продавать в демо-режиме нельзя**: код страницы открыт,
и любой может включить себе доступ. Для продаж нужен сервер — ниже шаги (1–2 часа, бесплатно на старте).

## 1. Сервер: Supabase (бесплатный тариф)

1. Зарегистрироваться на supabase.com → **New project** (регион — Frankfurt, ближе всего к Казахстану).
2. **SQL Editor → New query** → вставить весь файл `supabase/schema.sql` → **Run**.
   Это создаёт таблицы, права доступа и серверные функции (промокоды, оплата, баллы, рейтинг, родитель).
3. **Authentication → Providers → Email**: включено. Для старта можно выключить «Confirm email»,
   чтобы ученики входили сразу (потом лучше включить).
4. **Project Settings → API**: скопировать `Project URL` и `anon public` key в `js/config.js`:
   ```js
   window.Z.config = { supabaseUrl: 'https://xxxx.supabase.co', supabaseKey: 'eyJ...' };
   ```
   `anon` ключ — публичный, его можно хранить в коде. **`service_role` ключ в код не вставлять никогда.**

### Настройки безопасности входа (Supabase → Authentication)
- **Policies → Password**: минимум **8 символов**, «Lowercase, uppercase letters and digits» (или хотя бы «letters and digits»).
  Сайт и так не даёт слабый пароль, но правило на сервере обязательно — его нельзя обойти.
- **Leaked password protection** (если доступно на вашем тарифе): включить — не даст пароли из утечек.
- **Email → Confirm email**: включить, когда начнёте продавать (ученик подтверждает почту, чужую почту не занять).
- **Rate limits**: оставить по умолчанию — сервер сам ограничивает подбор пароля и частоту писем.
- **Attack Protection → CAPTCHA** (Cloudflare Turnstile): включить, если появятся боты-регистрации.
- **URL Configuration → Site URL / Redirect URLs**: адрес сайта (`https://zerde.kz`) — нужен для письма «Забыли пароль?».
- После обновления сайта ещё раз выполните `supabase/schema.sql`: он добавляет журнал активности (кто что делал),
  «последний вход», почту в профиле и журнал действий админа. Повторный запуск безопасен.

### Что видит админ («Әкімші → Оқушылар»)
Все пользователи: когда зарегистрировался и последний раз заходил, сколько тем освоено, домашки за 7 дней,
последний пробный, готовность, доступ. Нажмите на ученика — темы (освоил / в процессе / не начинал),
пробные и **журнал действий**: регистрация, входы, домашки с оценкой, уроки, пробные с баллом, карточки, игры,
промокоды и оплаты. Действия самих админов (подтверждение оплат, выдача доступа, промокоды) тоже пишутся в журнал.

### Заголовки безопасности хостинга
В папке лежат `_headers` (Netlify) и `vercel.json` (Vercel): запрет встраивания сайта в чужие страницы,
CSP (скрипты только с этого сайта и jsdelivr), HSTS. Ничего настраивать не нужно — хостинг подхватит сам.

## 2. Первый админ

Админом нельзя стать при регистрации — только промокодом. Первый промокод создайте в SQL Editor:
```sql
insert into public.promo_codes (code, kind, max_uses, note) values ('ВАШ-СЕКРЕТНЫЙ-КОД', 'admin', 2, 'основатели');
```
Зарегистрируйтесь на сайте и введите этот код в «Аккаунт → Промокод». Код для админа, созданный в админке,
по умолчанию одноразовый и действует 7 дней — передавайте его только лично. Дальше все промокоды
(для близких — «бесплатный доступ», скидки) создаются в разделе **«Әкімші / Админ → Промокоды»**.

## 3. Хостинг сайта

Сайт — обычные файлы, сборка не нужна. Варианты (бесплатно): **Netlify**, **Vercel**, **GitHub Pages** —
указать папку `zerde/`. Затем купить домен (например, `zerde.kz` через ps.kz) и привязать.

## 4. Оплата

Сейчас: ученик выбирает тариф → видит сумму и номер Kaspi → переводит → админ в разделе
**«Оплаты»** нажимает «Подтвердить» → доступ продлевается автоматически (1 / 3 / 6 месяцев).
В **«Админ → Настройки»** укажите номер Kaspi, имя получателя, цены, число бесплатных дней и призы месяца.

Позже, с ИП и договором эквайринга, можно подключить автоматическую оплату (Kaspi Pay, CloudPayments,
Freedom Pay): нужна серверная функция, которая по уведомлению платёжной системы вызывает то же
продление подписки. Это отдельный шаг.

## 5. Юридически (до первых продаж)

- **ИП** (через eGov, упрощённая декларация) — чтобы законно принимать оплату.
- **Публичная оферта** (условия, цены, возврат) и **политика конфиденциальности** — на сайте.
- Ученики — несовершеннолетние: в оферте указать, что регистрацию и оплату делает родитель или с его согласия.
- Призы в рейтинге: описать правила (как считаются баллы, когда подводятся итоги, кто не участвует — например, админы).

## Что где в коде

| Файл | Что |
|---|---|
| `supabase/schema.sql` | таблицы, права (RLS), серверные функции |
| `js/config.js` | подключение к Supabase (пусто → демо-режим) |
| `js/backend.js` | вход, роли, подписка, промокоды, оплата, баллы, рейтинг — демо и Supabase |
| `js/views.js` | лендинг, регистрация, тарифы, аккаунт, кабинет родителя, рейтинг, админка, карточки, игра |
| `tests/backend.js` | проверка логики аккаунтов: `node zerde/tests/backend.js` |

## Демо-промокоды (только в демо-режиме)

`ZERDE-ADMIN` — стать админом, `ZERDE-FREE` — бесплатный доступ. В боевом режиме их нет.
